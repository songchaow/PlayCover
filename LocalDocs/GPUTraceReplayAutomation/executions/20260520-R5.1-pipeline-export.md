## 1. 核心发现

### 1.1 ObjectMap 的 ForKey 方法签名

**关键突破**：所有 `ForKey:` 方法接受的参数类型是 **`uint64_t`**（ObjC type encoding `Q`），**不是** `id`/`NSObject`！

```
libraryForKey:                  -> @24@0:8Q16
renderPipelineStateForKey:      -> @24@0:8Q16
computePipelineStateForKey:     -> @24@0:8Q16
functionForKey:                 -> @24@0:8Q16
bufferForKey:                   -> @24@0:8Q16
textureForKey:                  -> @24@0:8Q16
```

调用方式：
```objc
id lib = ((id (*)(id, SEL, uint64_t))objc_msgSend)(objectMap, @selector(libraryForKey:), (uint64_t)key);
```

### 1.2 Key 空间布局

| 对象类型 | 存储位置 | Key 模式（reference trace） | Key 模式（papegames trace） |
|---------|---------|---------------------------|---------------------------|
| MTLLibrary | `libraryForKey:` | 6, 8, 10 | 248, 250, 252, ..., 438 (偶数) |
| MTLFunction | `functionMap` dict | 7, 9, 11 | 249, 251, 253, ..., 439 (奇数) |
| ComputePipelineState | `computePipelineStateForKey:` | 12, 13, 14 | (无) |
| RenderPipelineState | `renderPipelineStateForKey:` | (无) | 440~489 |
| MTLTexture/Buffer | `resources` dict | 0~3 | (大量) |

**观察到的模式**：Library key = Function key - 1（偶数/奇数交替对）

### 1.3 Library Binary 导出方法

| 方法 | 返回类型 | 用途 | 验证状态 |
|------|---------|------|---------|
| `libraryDataContents` | `NSConcreteData` | **metallib binary**（完整 Metal Library Archive） | ✅ |
| `bitcodeData` | `NSConcreteData` | **AIR bitcode**（LLVM IR wrapper） | ✅ |
| `serializeToURL:error:` | `BOOL` | 直接序列化到指定 URL | ✅ |

### 1.4 Pipeline State 类名

| GPU 系列 | Render | Compute |
|---------|--------|---------|
| M4 Pro (G16X) | `AGXG16XFamilyRenderPipeline` | `AGXG16XFamilyComputePipeline` |

## 4. _MTLLibrary 完整 binary-related 方法清单

```objc
@interface _MTLLibrary : _MTLObjectWithLabel <MTLLibrary>
// Binary export
- (id)libraryDataContents;     // → NSData (metallib binary) ✅
- (id)bitcodeData;             // → NSData (AIR/LLVM bitcode) ✅
- (BOOL)serializeToURL:(NSURL*)url error:(NSError**)error;  // ✅
- (void*)libraryData;          // → raw pointer (^v), 不安全
- (id)newMetalScript;          // Metal script 对象
- (id)newSpecializedFunctionWithHash:libraryPath:;
@end
```
