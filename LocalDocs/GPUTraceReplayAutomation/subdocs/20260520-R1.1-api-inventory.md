## 8. Harvester Blob 格式参考（R4.1 验证确认）

### 纹理 blob 结构（"capture" 格式）

```
Offset  Size  Field
0x00    8     Magic: "capture\0" (LE: 0x0063617074757265)
0x08    2     Version major (02 00)
0x0A    2     Version minor (01 00)
0x0C    4     Pixel format indicator
0x10    8     Plane count related
0x18    8*N   Plane descriptors (format, width, height, depth, bytesPerRow)
...
0x100   ...   Raw pixel data payload
```

### 解析逻辑

- `GTHarvesterGetData`：有 "capture" magic 时返回 `blob+0x100`（跳过 header）；无 magic 时直接返回 blob 起始
- `GTHarvesterGetMetadata`：有 magic 返回 blob 起始（header 即 metadata）；无 magic 返回 NULL
- `GTHarvesterGetTexturePlane(blob, idx)`：返回 `blob+24` 处第 idx 个 plane 描述符（32 bytes each）
- `GTHarvesterGetTexturePlaneCount`：读取 `blob+0x0A` 的 uint16 决定返回值

### 资源类型支持

| 资源类型 | Harvester 可解析 | 需要 replay? |
|---------|----------------|-------------|
| MTLTexture (capture fmt) | ✅ | ❌ |
| MTLBuffer (raw) | ✅ (直传) | ❌ |
| Pipeline binaries | ❌ (需 Fetch API) | ✅ |
| Profiling data | ❌ (需 Profile API) | ✅ |
