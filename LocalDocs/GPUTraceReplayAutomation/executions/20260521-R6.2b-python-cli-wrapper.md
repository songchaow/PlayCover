## 2. 架构设计

### 2.1 核心类：`ReplayBridge`

```python
from gputrace_replay_wrapper import ReplayBridge

bridge = ReplayBridge()              # 自动定位 bridge binary
bridge = ReplayBridge("/path/to/binary")  # 指定路径
```

### 2.2 方法签名

| 方法 | 返回类型 | 对应子命令 |
|------|---------|-----------|
| `bridge.help()` | `HelpResult` | help |
| `bridge.replay(trace, playto=N, list_resources=True, ...)` | `ReplayResult` | replay |
| `bridge.pipeline(trace, output_dir)` | `PipelineResult` | pipeline |
| `bridge.shader(trace, lib_key, metallib_path, verify=True)` | `ShaderResult` | shader |
| `bridge.config(trace, disable_optimize_restores=False, ...)` | `ConfigResult` | config |

### 2.3 数据模型（dataclass）

- `HelpResult` — tool, version, commands
- `ReplayResult` — success, elapsed_ms, resource_count, resources: list[Resource]
- `Resource` — id, type, width/height/length/label...
- `PipelineResult` — libraries: list[Library], functions, pipeline_states
- `Library` — key, functions, metallib_size, metallib_file...
- `ShaderResult` — replacement_done, original, replacement, verify
- `ConfigResult` — config dict, success, elapsed_ms

### 2.4 错误处理

| 异常类型 | 场景 | 退出码 |
|---------|------|--------|
| `FileNotFoundError` | .gputrace 路径不存在 | 2 |
| `ValueError` | 路径不是 .gputrace / 缺少参数 | 2 |
| `BridgeError` | bridge 返回非 0 退出码 | 原始退出码 |
| `TimeoutError` | 执行超时 | 124 |

### 2.5 CLI 用法

```bash
python3 gputrace_replay_wrapper.py help --pretty
python3 gputrace_replay_wrapper.py replay <trace> --list-resources --pretty
python3 gputrace_replay_wrapper.py pipeline <trace> <output_dir>
python3 gputrace_replay_wrapper.py shader <trace> <key> <metallib> --verify
python3 gputrace_replay_wrapper.py config <trace> disableOptimizeRestores=0
```
