## 实现内容

### 1. 子命令分发框架

基于函数指针表的子命令路由：

| 子命令 | 状态 | 功能 |
|--------|------|------|
| `help` | ✅ 完整 | JSON 输出可用子命令列表 |
| `replay` | ✅ 完整 | headless playAll + 计时 + 资源统计 |
| `pipeline` | 🔲 stub | 预留接口，R6.1c 实现 |
| `shader` | 🔲 stub | 预留接口，R6.1d 实现 |
| `config` | 🔲 stub | 预留接口，R6.1e 实现 |

### 2. JSON 输出宏

```c
JSON_BEGIN() / JSON_END()
JSON_KV_STR(k, v) / JSON_KV_INT(k, v) / JSON_KV_UINT(k, v)
JSON_KV_DOUBLE(k, v) / JSON_KV_BOOL(k, v) / JSON_KV_NULL(k)
json_print_string(s)  // 处理转义字符
```

自动逗号分隔，支持嵌套手动扩展。

### 3. 公共初始化（ReplayContext）

全局 `g_ctx` 结构体封装：
- dlopen GPUToolsReplay
- BL 偏移解析内部函数（apr_pool_create / makeDataSource / supportInit / initArgBuf / populateUnused / makeController / optimizeRestores）
- dlsym 导出函数（playAll / playTo / rewind）
- APR bootstrap + pool 创建
- makeDataSource → GTMTLReplayObjectMap initWithDevice: → initArgBuf → populateUnused → makeController
- 完整异常捕获链

### 4. 统一退出码

| Code | 含义 |
|------|------|
| 0 | 成功 |
| 1 | 用法错误 |
| 2 | 输入无效 |
| 3 | 无 Metal 设备 |
| 4 | dlopen 失败 |
| 5 | 符号解析失败 |
| 6 | APR 失败 |
| 7 | dataSource 失败 |
| 8 | objectMap 失败 |
| 9 | controller 失败 |
| 10 | replay 失败 |
| 11 | 子命令未实现 |
