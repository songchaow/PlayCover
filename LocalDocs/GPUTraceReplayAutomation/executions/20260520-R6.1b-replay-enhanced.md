## 实现内容

### 新增选项

```
replay <.gputrace> [--playto N] [--list-resources] [--export ID output_path]
```

| 选项 | 功能 |
|------|------|
| `--playto N` | 定向 replay 到 call index N（默认 playAll） |
| `--list-resources` | replay 后枚举 objectMap.resources，输出完整 JSON 数组 |
| `--export ID PATH` | 将指定资源 ID 的 raw data 导出为二进制文件 |

### 资源枚举输出格式

每个资源输出：
- **Texture**：id, type, width, height, depth, pixelFormat, pixelFormatName, textureType, mipmapLevelCount, label
- **Buffer**：id, type, length, label
- **Other**：id, type, class

### 辅助函数

- `bytes_per_pixel_for_format()` — 覆盖 20+ 常见 MTLPixelFormat
- `pixel_format_name()` — 可读格式名
- `texture_type_name()` — 1D/2D/3D/Cube/2DArray/2DMultisample
- `is_depth_stencil_format()` — 防止对 depth/stencil 调用 getBytes
- `parse_replay_options()` — argv 解析

### 导出逻辑

- Texture：`getBytes:bytesPerRow:fromRegion:mipmapLevel:` → 写文件
  - 排除 depth/stencil 格式（会崩）
  - 仅支持 2D 纹理
- Buffer：`[buf contents]` + memcpy → 写文件
- 错误处理：输出 `export_error` JSON 字段

```json
    {"id":5,"type":"buffer","length":1024},

  ]
}
```

✅ 4 个 buffer 全部正确枚举。

### V2: --playto 1（定向 replay）

```json
{"playto_index":1,"replay_rc":0,"elapsed_ms":0.006,"resource_count":4}
```

✅ 耗时从 0.178ms 降至 0.006ms，验证定向 replay 生效。

```
$ ./gputrace_replay_bridge replay <trace> --export 2 /tmp/buffer_2.bin

```

✅ Buffer 导出正确。
