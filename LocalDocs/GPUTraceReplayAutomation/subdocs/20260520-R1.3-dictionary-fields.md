# R1.3 技术参考：三层字典结构

**状态**：✅ 完成  
**核心结论**：headless replay（GTMTLReplay_CLI / Controller 路径）**均不需要**这些字典。字典仅在 XPC/DYGuestAppSession 通路有意义。

---

## 三层字典概览

| 层级 | 字典名 | 持有者 | 用途 |
|------|--------|--------|------|
| L1 | `finalLaunchDictionary` | DYGuestAppSession | 底层启动字典（10 键） |
| L2 | `replayerLaunchDictionary` | DYCaptureSession | replayer 专用（7 键） |
| L3 | `traceConfigurationDictionary` | DYGuestAppSession | profiling/trace 配置（7 键） |

## 对当前路径的指导

- **Controller 路径**（R4.2 主力）：直接接受 .gputrace 路径 + 程序化初始化，无需字典
- **CLI 路径**（R3）：直接接受 .gputrace 路径 + options 结构体，无需字典
- 若未来需通过 XPC/DYGuestAppSession 对象图触发 replay，需组装全部三层字典

## 环境变量级控制键

| 键名 | 作用 |
|------|------|
| `MTLREPLAYER_ALLOW_PROGRAM_ADDRESS_TABLES` | replayer 地址表 |
| `MTLREPLAYER_OVERRIDE_DEVICE_REGISTRY_ID` | 覆盖目标 GPU |
| `GPUTOOLS_FORCE_ROSETTA` | 强制 Rosetta |
| `GPUToolsUseOldTransport` | 旧版 transport |
