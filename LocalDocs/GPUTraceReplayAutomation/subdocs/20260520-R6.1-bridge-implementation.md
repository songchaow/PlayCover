## 3. 子命令详情

### 3.1 replay

```
replay <.gputrace> [--playto N] [--list-resources] [--export ID output_path]
```

- `--playto N`：定向 replay 到 call index N
- `--list-resources`：枚举 objectMap.resources（Texture: id/width/height/pixelFormat/label; Buffer: id/length/label）
- `--export ID PATH`：资源导出（Texture: getBytes, Buffer: contents）
- 辅助：`bytes_per_pixel_for_format()`(20+ 格式)、depth/stencil 排除

### 3.2 pipeline

```
pipeline <.gputrace> [output_dir]
```

- Library 枚举（key 空间扫描：functionMap maxKey + 50 headroom）
- 每个 library 导出 `library_<key>.metallib` + `library_<key>.air`
- Render/Compute PipelineState 枚举
- Function 枚举（name + functionType）

### 3.3 shader

```
shader <.gputrace> <lib_key> <metallib_path> [--verify]
shader <.gputrace> <lib_key> --source <msl_path> [--verify]
```

- metallib binary 替换：`newLibraryWithData:` → `setLibrary:forKey:`
- MSL source 编译替换：`newLibraryWithSource:options:error:` → `setLibrary:forKey:`
- `--verify`：替换后 rewind + playAll 验证

### 3.4 config

```
config <.gputrace> [key=value ...]
```

| Key | 默认 | 控制点 |
|-----|------|--------|
| `disableOptimizeRestores=0|1` | 1 | 跳过 optimizeRestores 调用 |
| `forceLoadUnusedResources=0|1` | 1 | populateUnusedResources |
| `enableValidation=0|1` | 0 | g_runningValidationCI 全局变量 |

独立 `config_replay_with_options()` 函数，每次创建独立上下文。
