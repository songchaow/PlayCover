## 实现内容

### 用法

```
gputrace_replay_bridge pipeline <.gputrace> [output_dir]
```

### 功能

1. **Library 枚举**：扫描 objectMap 所有 key（0..maxKey），通过 `libraryForKey:(uint64_t)` 获取 MTLLibrary
2. **metallib 导出**：`libraryDataContents` → NSData → 写 `library_<key>.metallib`
3. **AIR bitcode 导出**：`bitcodeData` → NSData → 写 `library_<key>.air`
4. **Render/Compute Pipeline State 枚举**：`renderPipelineStateForKey:` / `computePipelineStateForKey:`
5. **Function 枚举**：`objectMap.functionMap` → name + functionType（vertex/fragment/kernel）

### JSON 输出字段

```json
{
  "command": "pipeline",
  "trace_path": "...",
  "device": "Apple M4 Pro",
  "output_dir": "...",
  "libraries": [...],
  "render_pipeline_states": [...],
  "compute_pipeline_states": [...],
  "functions": [...],
  "libraries_count": N,
  "metallibs_exported": N,
  "bitcodes_exported": N,
  "render_pipeline_states_count": N,
  "compute_pipeline_states_count": N,
  "functions_count": N
}
```

每个 library 条目包含：key, class, function_count, functions[], installName, label, metallib_size, metallib_magic, metallib_file, bitcode_size, bitcode_magic, bitcode_file

### Key 空间扫描策略

从 `objectMap.functionMap` 获取最大 key + 50 的 headroom 作为扫描上限。
