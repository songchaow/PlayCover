# 04 - 现有 Metal Shader 逆向/反汇编工具

## 一、工具矩阵

| 工具 | 作者 | 输入 | 输出 | 适用场景 |
|---|---|---|---|---|
| **MetalLibraryArchive** | YuAo | `.metallib` | 函数列表、LLVM Bitcode、嵌入源码 | 从 metallib 提取 AIR |
| **MetalShaderTools** | zhuowei | `.metallib` | LLVM Bitcode → x86/ARM 汇编 | 学术分析 |
| **applegpu** | dougallj | `.metallib` / GPU native binary | **Apple GPU ISA 反汇编** | 真正的 GPU 汇编 |
| `llvm-dis` | LLVM | `.air` (Bitcode) | 可读 LLVM IR 文本 | 中间表示分析 |
| `xcrun metal-objdump` | Apple | `.metallib` | Metal IR 反汇编 | 官方工具 |

## 二、MetalLibraryArchive（最成熟）

- GitHub: https://github.com/YuAo/MetalLibraryArchive
- 语言: Swift
- 许可: MIT
- Web 版: https://yuao.github.io/MetalLibraryExplorer

**功能**：
```swift
import MetalLibraryArchive
let archive = try Archive(data: Data(contentsOf: metallibURL))
for function in archive.functions {
    print(function.name)     // 函数名
    print(function.type)     // vertex/fragment/kernel
    print(function.bitcode)  // LLVM Bitcode bytes → 可用 llvm-dis 反汇编
}
```

**限制**：只能处理 `.metallib` 文件，不能直接处理 gputrace 中的 pipeline state binary。

## 三、applegpu（Apple GPU ISA 反汇编器）

- GitHub: https://github.com/dougallj/applegpu
- 文档: https://dougallj.github.io/applegpu/docs.html
- 目标: Apple G13 GPU 架构（M1），基于逆向工程

**Compiler Explorer 风格工具**：
```bash
# 从 MSL 源码编译并反汇编
echo "kernel void test(...) { ... }" | python3 compiler_explorer.py -

# 从 metallib 提取并反汇编
python3 compiler_explorer.py shader.metallib
```

**输出示例**（真正的 GPU 汇编）：
```
compute shader:
   0: f2091004     get_sr     r2.cache, sr80 (thread_position_in_grid.x)
   4: f20d1204     get_sr     r3.cache, sr82 (thread_position_in_grid.z)
   8: 0e01881900   isub       r0, u4, 1
```

**限制**：
- 基于逆向工程，可能有错误
- 主要支持 G13 (M1)，其他 GPU 代可能有差异
- 需要从 metallib 提取 native binary，不能直接处理 gputrace 中已编译的 pipeline

## 四、Apple 官方工具

### `xcrun metal-objdump`
```bash
xcrun metal-objdump -disassemble shader.metallib
```

反汇编 Metal IR（非 GPU native code）。

### `xcrun metal-source`
```bash
# 提取嵌入的源码
xcrun metal-source -extract -o ./sources/ shader.metallibdsym

# 附加源码到 metallibdsym
xcrun metal-source -add-sources ./shader.metal -o shader.metallibdsym
```

### `dwarfdump`
```bash
# 查看 DWARF 调试信息
xcrun dwarfdump --all shader.metallibdsym

# 验证 UUID 匹配
dwarfdump --uuid shader.metallib
dwarfdump --uuid shader.metallibdsym/Contents/Resources/DWARF/*
```
