## 三、当前结论摘要

本轮最重要的新结论有两个：

1. **`install_ipa` 的 MCP 路径与 GUI 原生安装路径存在不一致风险**  
   对给定 IPA，通过 MCP `install_ipa` + `get_task` 最终稳定失败，错误为：
   `MachO conversion failed: No ARM64 architecture found in fat binary`；但用户明确反馈**同一 IPA 在 GUI 中可以安装成功**。

2. **旧文档中的部分手测路径已经过期**  
   旧的 `G04/G08` 文档仍按“raw TCP + `nc localhost 19820`”描述手测步骤，但当前 GUI 实际暴露的是 **streamable HTTP MCP**（`/mcp`）。直接走旧 raw TCP initialize 路径会得到 `400 Bad Request`，不应再作为当前正确手测方法。

另外，本轮还确认了一条重要的**环境注意事项**：

- 如果旧的 `PlayCoverMCP` CLI 进程仍占用 `52741`，会导致 GUI 路径下 `create_session` 超时；清理残留 CLI 后，fresh live 环境中的 session / touch / input 主链路可恢复正常。这个更像**测试环境冲突**，暂不单列为产品 bug，但必须保留给后续测试者参考。
