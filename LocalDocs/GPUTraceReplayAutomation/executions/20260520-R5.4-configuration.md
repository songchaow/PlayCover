## 2. 接口完整确认

### GTReplayConfiguration（13 BOOL 属性）

```objc
@interface GTReplayConfiguration : NSObject <NSSecureCoding>
@property BOOL forceLoadActionClear;          // 强制 load action 清零
@property BOOL forceLoadUnusedResources;      // 强制加载未使用资源
@property BOOL forceResourcesResident;        // 强制所有资源常驻
@property BOOL forceWaitUntilCompleted;       // 强制每个 cmdBuf 同步等待
@property BOOL disableOptimizeRestores;       // 禁用 restore 优化
@property BOOL disableHeapTextureCompression; // 禁用堆纹理压缩
@property BOOL enableStopOnError;             // 遇错停止
@property BOOL enableDisplayOnDevice;         // 设备显示
@property BOOL enableReplayFromOtherPlatforms;// 跨平台 replay
@property BOOL enableValidation;              // Metal 验证层
@property BOOL enableCapture;                 // 嵌套截帧
@property BOOL enableHUD;                     // HUD 叠加
@property BOOL enableLiveICBs;                // 实时 ICB 重编码
@end
```

**所有属性默认值为 NO**（已验证）。支持 `NSSecureCoding`（XPC 序列化）。

### GTReplayUpdateConfiguration

```objc
@interface GTReplayUpdateConfiguration : GTReplayRequest <NSSecureCoding>
@property (nonatomic, strong) GTReplayConfiguration *configuration;
@end
```

### GTMTLReplayService

```objc
@interface GTMTLReplayService
- (id)update:(GTReplayUpdateConfiguration *)request;
- (id)initWithContext:(GTMTLReplayClient *)context;
@end
```

`initWithContext:` 接受 `GTMTLReplayClient*`，类型编码揭示内部结构包含 `apr_pool_t*`、`GTMTLReplayController*`、timing info、**4 个 config bitfield**、objectMap 等。

## 3. 验证数据

### TEST A: disableOptimizeRestores（调用链控制）

| 条件 | Trace | playAll 时间 | 效果 |
|------|-------|-------------|------|
| WITH optimizeRestores | reference_test_inject | 0.041 ms | baseline |
| WITHOUT optimizeRestores | reference_test_inject | 0.118 ms | +188% |
| WITH optimizeRestores | Papegames 大 trace | 3.861 ms | baseline |
| WITHOUT optimizeRestores | Papegames 大 trace | 10.346 ms | +168% |

**结论**：`GTMTLReplayController_optimizeRestores`（CLI+0x96c）是 `disableOptimizeRestores` 属性的直接映射。跳过该调用 = disableOptimizeRestores=YES。效果：**2.7x 慢**。

### TEST B: forceLoadUnusedResources（调用链控制）

| 条件 | Resources Count |
|------|----------------|
| 跳过 populateUnusedResources | 4 (ref) / 262 (papegames) |
| 调用 populateUnusedResources | 4 (ref) / 262 (papegames) |

**结论**：测试 trace 没有 unused resources（资源数不变）。调用链映射已确认：`populateUnusedResources` = forceLoadUnusedResources=YES 的效果。

### TEST C: enableValidation（全局变量）

| 条件 | Trace | playAll 时间 |
|------|-------|-------------|
| g_runningValidationCI=0 | Papegames | 10.721–11.498 ms |
| g_runningValidationCI=1 | Papegames | 11.121–13.984 ms |

**结论**：全局变量 `g_runningValidationCI`（导出符号地址 `0x2a57843e1`）控制 Metal validation layer。开启后 playAll 增加 3.7–21.6% 时间开销。

### TEST D: Service.update: 路径

- `GTMTLReplayService.update:` 实例方法存在 ✅
- `[GTMTLReplayService alloc] init]` 可创建空实例
- 调用 `update:` 时崩溃 — 需要通过 `initWithContext:` 用完整 `GTMTLReplayClient` 结构体初始化
- `GTMTLReplayClient` 结构体包含：pool、controller、timing、**config bitfields**、objectMap、wireframe renderer、operation queues

## 4. Configuration 属性→Controller 路径映射总览

| # | Configuration 属性 | Controller 路径等价操作 | 验证 |
|---|-------------------|----------------------|------|
| 1 | `disableOptimizeRestores` | 跳过 `GTMTLReplayController_optimizeRestores(ctrl)` | ✅ 效果 168–188% |
| 2 | `forceLoadUnusedResources` | 调用 `populateUnusedResources(ds, om)` | ✅ 调用链确认 |
| 3 | `enableValidation` | 写入 `g_runningValidationCI = YES` | ✅ 3.7–21.6% overhead |
| 4 | `forceWaitUntilCompleted` | GTMTLReplayClient config bitfield 第4位 | ⚠️ 结构已定位 |
| 5 | `forceLoadActionClear` | 内部 render pass level 控制 | 🔍 需 replay 内部逻辑 |
| 6 | `forceResourcesResident` | MTLResource.makeResident | 🔍 需 replay 内部逻辑 |
| 7 | `disableHeapTextureCompression` | MTLHeap 压缩控制 | 🔍 需 replay 内部逻辑 |
| 8 | `enableStopOnError` | Error handler 控制 | 🔍 需 replay 内部逻辑 |
| 9 | `enableDisplayOnDevice` | CAMetalLayer presentDrawable | 🔍 headless 下无意义 |
| 10 | `enableReplayFromOtherPlatforms` | 平台兼容模式 | 🔍 需 replay 内部逻辑 |
| 11 | `enableCapture` | MTLCaptureManager | 🔍 嵌套截帧 |
