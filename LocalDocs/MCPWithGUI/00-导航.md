# MCPWithGUI 文档导航

## 本文档集的目标

规划并指导在 PlayCover.app 图形界面中嵌入 MCP Server 的实施工作（方案 A2：进程内 TCP Transport）。

## 文档结构

| 文档 | 内容 | 何时阅读 |
|------|------|---------|
| **00-导航.md**（本文件） | 文档索引与概览 | 最先读 |
| **01-总体规划与需求.md** | 背景、选型理由、目标、工作量总估、风险 | 理解全貌 |
| **02-技术方案详解.md** | TCPTransport 设计、命名冲突解决、集成方式、状态联动方案 | 动手前精读 |
| **03-任务分解与执行顺序.md** | G01-G08 任务卡、依赖关系、推荐执行顺序 | 领取任务时 |
| **04-现状代码锚点.md** | GUI 和 MCP 两侧的关键代码位置速查 | 编码时随时查 |

## 与现有 MCP 文档的关系

本文档集（`LocalDocs/MCPWithGUI/`）是 `LocalDocs/MCP/` 的**后续扩展**：

- `LocalDocs/MCP/` — MCP CLI Server 的设计与实现（已完成的 Phase 0-1）
- `LocalDocs/MCPWithGUI/` — 将 MCP 嵌入 GUI 的设计与实现（本轮新需求）

本轮工作**不会**修改 MCP 的对外协议和功能集，只新增 TCP transport 并嵌入 GUI 进程。

## 前置知识

实施本轮工作的 agent 应先阅读：

1. `LocalDocs/MCP/01-总体规划与架构.md`（理解 MCP 整体架构）
2. `LocalDocs/MCP/03-共享前置信息.md`（仓库事实与代码锚点）
3. 本目录下的所有文档

## 核心约束

1. **不改变 MCP 对外协议**：JSON-RPC 消息格式、tool/resource 定义均不变
2. **保留独立 CLI**：`PlayCoverMCP` CLI target 继续存在，stdio 模式不受影响
3. **GUI 零功能回退**：嵌入 MCP 后，GUI 原有的所有功能必须正常工作
4. **最小侵入原则**：优先新增代码，避免大规模重构现有 GUI 或 MCP 代码
