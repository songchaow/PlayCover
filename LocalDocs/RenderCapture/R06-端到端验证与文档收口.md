### 端到端测试步骤

#### 场景 1：基本截帧流程

1. 在 PlayCover 中安装一个使用 Metal 的 iOS app
2. 检查 app 的 Info.plist 包含 `MetalCaptureEnabled = YES`
3. 在设置中启用 `metalCaptureEnabled`
4. 启动 app
5. 通过 MCP `capture_metal_frame` 工具触发截帧
6. 检查 `.gputrace` 文件生成
7. 尝试用 Xcode 打开 `.gputrace` 文件

#### 场景 2：截帧状态查询

1. 启动一个配置了 Metal Capture 的 app
2. 通过 MCP `get_capture_status` 查询状态
3. 确认返回 `available: true, enabled: true`

#### 场景 3：未启用时的行为

1. 安装 app 但不启用 `metalCaptureEnabled`
2. 启动 app
3. 通过 MCP `get_capture_status` 查询状态
4. 确认返回 `enabled: false`
5. 尝试 `capture_metal_frame`，确认返回合理的错误信息

#### 场景 4：GUI 设置界面

1. 打开 app 设置
2. 确认 Metal Capture Toggle 可见且可操作
3. 切换开关，确认设置保存
4. 重启 PlayCover，确认设置保持
