# R5.4 技术参考：Configuration 动态修改

**状态**：✅ 验证完成  
**方法**：V1 静态 introspection + V4 最小样本动态验证

---

## 1. 核心结论

Configuration 在 Controller 路径下通过三种机制动态修改：

| 机制 | 覆盖属性 | 验证状态 |
|------|---------|---------|
| **调用链控制**（跳过/调用特定初始化步骤） | `disableOptimizeRestores`, `forceLoadUnusedResources` | ✅ |
| **全局变量直接写入** | `enableValidation` (`g_runningValidationCI`) | ✅ |
| **Service.update: 路径** | 所有 13 属性 | ⚠️ 需完整 GTMTLReplayClient context |

---

## 2. GTReplayConfiguration（13 BOOL 属性）

```objc
@interface GTReplayConfiguration : NSObject <NSSecureCoding>
@property BOOL forceLoadActionClear;
@property BOOL forceLoadUnusedResources;
@property BOOL forceResourcesResident;
@property BOOL forceWaitUntilCompleted;
@property BOOL disableOptimizeRestores;
@property BOOL disableHeapTextureCompression;
@property BOOL enableStopOnError;
@property BOOL enableDisplayOnDevice;
@property BOOL enableReplayFromOtherPlatforms;
@property BOOL enableValidation;
@property BOOL enableCapture;
@property BOOL enableHUD;
@property BOOL enableLiveICBs;
@end
```

所有属性默认值 NO。支持 `NSSecureCoding`（XPC 序列化）。

---

## 3. 属性→Controller 路径映射

| # | 属性 | Controller 路径操作 | 验证 |
|---|------|-------------------|------|
| 1 | `disableOptimizeRestores` | 跳过 `GTMTLReplayController_optimizeRestores(ctrl)`（CLI+0x96c） | ✅ 168–188% 性能差异 |
| 2 | `forceLoadUnusedResources` | 调用 `populateUnusedResources(ds, om)` | ✅ 调用链确认 |
| 3 | `enableValidation` | 写入 `g_runningValidationCI = YES`（导出符号 0x2a57843e1） | ✅ 3.7–21.6% overhead |
| 4 | `forceWaitUntilCompleted` | GTMTLReplayClient config bitfield 第4位 | ⚠️ 结构已定位 |
| 5-8 | 其他运行时属性 | 需 replay 内部逻辑级控制 | 🔍 |
| 9,12 | `enableDisplayOnDevice`/`enableHUD` | headless 下无意义 | — 跳过 |
| 10-13 | 其余 | 通过 Service 路径或未导出内部函数 | 🔍 |

---

## 4. Service 完整路径

```objc
@interface GTReplayUpdateConfiguration : GTReplayRequest <NSSecureCoding>
@property (nonatomic, strong) GTReplayConfiguration *configuration;
@end

@interface GTMTLReplayService
- (id)update:(GTReplayUpdateConfiguration *)request;
- (id)initWithContext:(GTMTLReplayClient *)context;
@end
```

`initWithContext:` 需完整 `GTMTLReplayClient` 结构体（pool + controller + timing + 4 config bitfield + objectMap + wireframe renderer + operation queues）。

## 5. R6.1 集成推荐

```objc
// 方式 1：调用链控制（已验证的 3 项，推荐优先实现）
if (!config.disableOptimizeRestores) optimizeRestores(controller);
if (config.forceLoadUnusedResources) populateUnusedResources(dataSource, objectMap);
if (config.enableValidation) *(BOOL *)g_runningValidationCI_ptr = YES;

// 方式 2：完整 Service 路径（覆盖全部 13 项，需额外逆向 GTMTLReplayClient 布局）
```
