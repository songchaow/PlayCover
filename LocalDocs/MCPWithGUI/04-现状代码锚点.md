# 现状代码锚点

本文档列出实施方案 A2 时需要重点了解的现有代码位置和结构。

## GUI 侧关键代码

### 入口与生命周期

- **App 入口**：`PlayCover/Views/PlayCoverApp.swift`
  - `PlayCoverApp: App`（@main SwiftUI App）
  - `AppDelegate: NSObject, NSApplicationDelegate`
  - `applicationDidFinishLaunching` — 当前做更新检查、KeyCover 初始化
  - `applicationShouldTerminateAfterLastWindowClosed` — 返回 true
  - **无** `applicationWillTerminate` 方法（需新增）

### 应用列表管理

- **ViewModel**：`PlayCover/ViewModel/AppsVM.swift`
  - `AppsVM: ObservableObject`，单例 `shared`
  - `@Published var apps: [PlayApp]` / `@Published var filteredApps: [PlayApp]`
  - `fetchApps()` — 扫描 `appDirectory` 磁盘目录
  - **无文件系统监听**，纯事件驱动刷新

- **调用 fetchApps() 的位置**：
  - `AppsVM.init()`（初始化时）
  - `AppLibraryView.onAppear`（视图出现时）
  - `AppLibraryView.onChange(of: searchString)`（搜索变化时）
  - `PlayApp.launch()`（启动前刷新一次）
  - `PlayApp.deleteApp()`（删除后刷新）
  - `Installer` 安装回调
  - `Downloader` 下载完成回调
  - `AppSettingsView` 某些操作后

### Shell 工具

- **GUI Shell**：`PlayCover/Utils/Shell.swift`
  - `class Shell: ObservableObject` — 带 UI 状态的 shell 执行器

### 应用数据目录

- **路径**：`PlayTools.playCoverContainer.appendingPathComponent("Applications")`
  - 展开为：`~/Library/Containers/io.playcover.PlayCover/Applications/`

## MCP 侧关键代码

### 入口

- **CLI 入口**：`PlayCoverMCP/main.swift`
  - 创建所有 Service → 注册到 MCPServer → 创建 StdioTransport → `transport.run()`
  - `transport.run()` 内部调用 `RunLoop.main.run()` 永久阻塞

### Server 核心

- **MCPServer**：`PlayCoverMCP/Server/MCPServer.swift`
  - JSON-RPC 请求分发器
  - 注册 method/tool/resource handler
  - 与 transport 完全解耦（通过 `handle(JSONRPCMessage) -> JSONRPCMessage?`）

### Transport

- **StdioTransport**：`PlayCoverMCP/Transport/StdioTransport.swift`
  - stdin/stdout 行分隔 JSON-RPC
  - `run()` 阻塞主线程
  - `MessageHandler = (JSONRPCMessage) -> JSONRPCMessage?`

## 共享磁盘路径

两者操作相同的文件系统位置：

| 路径 | 用途 |
|------|------|
| `~/Library/Containers/io.playcover.PlayCover/Applications/` | 已安装应用目录 |
| `~/Library/Containers/io.playcover.PlayCover/Entitlements/` | 应用 entitlements |
| `~/Library/Containers/io.playcover.PlayCover/Keymapping/` | 键位映射文件 |
| `~/Library/Frameworks/PlayTools.framework/` | PlayTools 框架 |
