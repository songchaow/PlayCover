# R5.2 技术参考：Shader 热替换（GTReplayUpdateLibrary）

**状态**：✅ 验证成功  
**方法**：V1 静态 introspection + V4 最小样本动态验证

---

## 1. 核心结论

- ✅ **shaderSource** 路径可用（MSL → 编译 → 替换）
- ✅ **shaderIR** 路径可用（metallib binary → 加载 → 替换，**无需源码**）
- ✅ 替换确实影响 GPU 输出（buffer 内容改变）
- ✅ 可恢复原始状态（rewind+playAll 后 baseline 对齐）
- ⚠️ AIR bitcode 不能直接 `newLibraryWithData:`（需先 `xcrun metallib` 转换）
- ⚠️ 函数名不匹配时不报错（pipeline 缓存旧函数指针，需在 rewind 后 populate 前替换）
- 🎯 **Xcode UI 未暴露能力**：shaderIR binary 注入可用于无源码 shader 替换

---

## 2. 两条替换路径

| 路径 | 方法 | 复杂度 | 状态 |
|------|------|--------|------|
| **A（推荐）** | `objectMap.setLibrary:forKey:` → rewind → playAll | 低 | ✅ |
| B（Service） | `GTMTLReplayService.update:(GTReplayUpdateLibrary)` | 高（需完整 client） | 接口确认 |

---

## 3. GTReplayUpdateLibrary 接口

```objc
@interface GTReplayUpdateLibrary : GTReplayRequest <NSSecureCoding>
@property (nonatomic) struct { struct { int; int; } dispatchUID; uint64_t; } dispatchUID;
@property (nonatomic) uint64_t streamRef;
@property (nonatomic, strong) NSURL *shaderURL;
@property (nonatomic, strong) NSData *shaderIR;        // metallib binary
@property (nonatomic, strong) NSString *shaderSource;  // Metal Shading Language
@end
```

`setLibrary:forKey:` 签名：`v32@0:8@16Q24`（void, id+uint64_t）

---

## 4. 推荐调用流程（路径 A）

```objc
// 1. 准备新 library
NSData *newMetallib = ...;  // shaderIR: metallib binary
dispatch_data_t dd = dispatch_data_create(newMetallib.bytes, newMetallib.length, NULL, DISPATCH_DATA_DESTRUCTOR_DEFAULT);
id<MTLLibrary> newLib = [device newLibraryWithData:dd error:&err];
// 或从源码：[device newLibraryWithSource:mslSource options:opts error:&err]

// 2. 替换
((void (*)(id, SEL, id, uint64_t))objc_msgSend)(objectMap, @selector(setLibrary:forKey:), (id)newLib, libraryKey);

// 3. Rewind + Replay
GTMTLReplayController_rewind(controller);
int rc = GTMTLReplayController_playAll(controller);

// 4. 读取结果验证
NSDictionary *resources = [objectMap resources];
```
