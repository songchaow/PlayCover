## 3. 核心 XPC 代理：GTMTLReplayServiceXPCProxy

这是 **replay 操作的统一入口**。所有 GUI 操作最终都通过这个代理发送 XPC 消息：

```objc
@interface GTMTLReplayServiceXPCProxy
// --- 生命周期 ---
- (id)initWithConnection:(id)connection serviceInfo:(id)info;
- (id)load:(id)arg error:(NSError **)error;
- (void)terminateProcess;

// --- Replay 控制 ---
- (void)pause:(id)token;
- (void)resume:(id)token;
- (void)cancel:(id)token;

// --- 数据获取（核心） ---
- (void)fetch:(GTReplayFetch*)request;          // 获取纹理/buffer/pipeline 等
- (void)fetchInto:(GTReplayFetchInto*)request;  // 获取到指定目的地
- (void)query:(GTReplayQuery*)request;          // 查询 counters/performance/config
- (void)profile:(GTReplayProfile*)request;      // profiling 数据
- (void)decode:(GTReplayDecode*)request;        // 解码 ICB/AS
- (void)display:(GTDisplay*)request;            // 显示相关
- (void)raytrace:(GTReplayRaytraceRequest*)req; // 光追可视化
- (void)shaderdebug:(GTReplayShaderDebugRequest*)req; // shader 调试
- (void)update:(GTReplayUpdate*)request;        // 更新 shader/config

// --- 状态 ---
- (void)registerObserver:(id)observer;
- (void)deregisterObserver:(id)observer;
- (void)flushRpackets;

@property processInfo, serviceProperties, deviceUDID, servicePort;
@end
```

## 4. Fetch 类族（数据获取 request 对象）

所有 Fetch 类共享 `dispatchUID` 属性（标识目标 GPU 资源）。

| 类 | 用途 | 关键属性 |
|----|------|---------|
| **GTReplayFetchTexture** | 获取纹理数据 | streamRef, slice, level, depth, plane, size, region, resolveMultisampleTexture |
| **GTReplayFetchBuffer** | 获取 buffer 数据 | streamRef, range |
| **GTReplayFetchPipelineBinaries** | 获取 pipeline 编译产物 | streamRef |
| **GTReplayFetchPostVertex** | 获取变换后顶点 | objectShaderThreadgroupBoundsPresent, Begin/End |
| **GTReplayFetchThreadgroup** | 获取线程组数据 | index |
| **GTReplayFetchWireframe** | 获取线框数据 | solid |
| **GTReplayFetchImageBlock** | 获取 Image Block | index |
| **GTReplayFetchInto** | 获取到目标位置 | dest, event |
| **GTReplayFetchIntoTexture** | 渲染到纹理 | streamRef, slice, level, depth, plane, resolveMultisampleTexture |
| **GTReplayFetchMLGraph** | 获取 ML 图 | pipelineRef |
| **GTReplayFetchMLGraphData** | 获取 ML 图数据 | pipelineRef, mlModuleKey, mlResourceKey |
| **GTReplayFetchMLIntermediateData** | 获取 ML 中间数据 | pipelineRef, intermediateOps |

## 13. 对后续任务的关键启示

1. **GTMTLReplayServiceXPCProxy** 定义了完整操作集 — Controller 路径下需确认哪些操作可绕过 XPC 直接执行
2. **GTReplayUpdateLibrary** 支持 shader 热替换（shaderSource/shaderIR/shaderURL）— R5.1 关键路径
3. **GTReplayProfileTimeline.shaderProfiling** 是 shader profiler 数据开关 — R4.5 关键
4. **GTReplayQueryDerivedCounters** + **GPURawCounter** 双路径获取 GPU 计数器 — R4.4 关键
5. 所有 request 对象支持 `NSCoding`（XPC 序列化），Controller 路径下需确认是否也能直接实例化使用
