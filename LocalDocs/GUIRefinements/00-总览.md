## PlayCover GUI 增强功能

### 文档目的

本目录记录 PlayCover **GUI 原生界面**的功能扩展。

这些功能利用了 MCP 底层的 session / capture 基础设施，但本质上是 **PlayCover App 库 UI 层面的增强**，而不是 MCP 协议或工具层面的新增。

### 当前包含的功能

| 功能 | 文档 | 涉及 commit |
|---|---|---|
| App 条目 Session 状态指示器 | `01-Session状态指示器.md` | `4341f2d1` |
| App 条目 Metal 截帧按钮 | `02-Metal截帧按钮.md` | `4a7d466b` |

### 功能定位

这些功能的共同特点是：

1. **在 App 库的每个 app 条目上增加可视化信息或交互控件**
2. **数据来源于 MCP 内部的 SessionRegistry / CaptureService**
3. **通过 MCPManager 单例桥接，不依赖 HTTP 协议层**
4. **用户无需了解 MCP 即可使用**

### 架构桥接方式

```text
PlayCoverMCP (后端)                      PlayCover GUI (前端)
─────────────────                        ────────────────────
SessionRegistry                          MCPManager (@Published)
  │ onChange callback                       │ runtimeSessions
  │ (snapshot of [SessionInfo])             │ capturingBundleIds
  └──────────────────────────────────────▶  │
                                            ▼
CaptureService                           PlayAppConditionalView
  │ captureFrame / getCaptureStatus         ├─ SessionIndicatorView (列表)
  └──────────────────────────────────────▶  ├─ SessionDotView (网格)
     MCPManager.captureFrame(bundleId:)     └─ CaptureButton (列表 + 网格)
```

核心设计原则：

- **无跨 target 类型依赖**：GUI target 不直接引用 `SessionInfo` / `SessionStatus` 类型，而是通过 `RuntimeSessionSnapshot`（字符串状态）解耦
- **主线程安全**：`SessionRegistry.onChange` 回调在 `DispatchQueue.main.async` 中派发
- **不影响 CLI**：CLI 入口不设置 `onChange`，回调默认 `nil`

### 关键源码位置

| 文件 | 角色 |
|---|---|
| `PlayCover/Views/App Views/PlayAppView.swift` | 所有 GUI 增强视图的实现 |
| `PlayCover/Services/MCPManager.swift` | `RuntimeSessionSnapshot`、session 快照发布、capture 方法 |
| `PlayCoverMCP/Session/SessionRegistry.swift` | `onChange` 回调（数据源） |
| `PlayCoverMCP/Session/CaptureService.swift` | capture 执行层 |
