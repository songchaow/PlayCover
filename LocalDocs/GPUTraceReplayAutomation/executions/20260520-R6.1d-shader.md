## 实现内容

### 用法

```
gputrace_replay_bridge shader <.gputrace> <lib_key> <metallib_path> [--verify]
gputrace_replay_bridge shader <.gputrace> <lib_key> --source <msl_path> [--verify]
```

### 功能

1. **metallib binary 替换（无源码）**：读取 .metallib 文件 → `newLibraryWithData:` → `setLibrary:forKey:`
2. **MSL source 编译替换**：读取 .metal 文件 → `newLibraryWithSource:options:error:` → `setLibrary:forKey:`
3. **rewind + playAll 验证**（`--verify`）：替换后重放，确认 replay 成功
4. **完整 JSON 输出**：替换前后 library 信息（大小、函数列表）+ 验证结果

### 替换核心调用

```objc
// 从 metallib binary
dispatch_data_t dd = dispatch_data_create(data.bytes, data.length, ...);
id<MTLLibrary> newLib = [device newLibraryWithData:dd error:&err];

// 替换
objc_msgSend(objectMap, @selector(setLibrary:forKey:), newLib, key);

// 验证
rewind(controller);
playAll(controller);
```

### JSON 输出字段

```json
{
  "command": "shader",
  "trace_path": "...",
  "library_key": N,
  "replacement_done": true,
  "original": { "exists": true, "metallib_size": N, "functions": [...] },
  "replacement": { "metallib_size": N, "metallib_path|source_path": "...", "functions": [...] },
  "verify": { "playAll_rc": 0, "success": true, "elapsed_ms": 0.141 }
}
```
