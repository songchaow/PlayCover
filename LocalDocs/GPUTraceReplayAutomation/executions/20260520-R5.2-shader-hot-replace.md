## 2. 关键发现

### 2.1 GTReplayUpdateLibrary 完整接口

```objc
@interface GTReplayUpdateLibrary : GTReplayRequest <NSSecureCoding>
@property (nonatomic) struct { struct { int; int; } dispatchUID; uint64_t; } dispatchUID;
@property (nonatomic) uint64_t streamRef;
@property (nonatomic, strong) NSURL *shaderURL;
@property (nonatomic, strong) NSData *shaderIR;        // ⭐ metallib binary
@property (nonatomic, strong) NSString *shaderSource;  // Metal Shading Language
@end
```

- 继承自 `GTReplayRequest`
- 实现 `NSSecureCoding`（XPC 序列化）
- `dispatchUID` 类型编码：`(?={?=ii}Q)` — 内含 2 个 int + 1 个 uint64

### 2.2 两条可用替换路径

| 路径 | 方法 | 复杂度 | 状态 |
|------|------|--------|------|
| **A（直接替换）** | `objectMap.setLibrary:forKey:` → rewind → playAll | 低 | ✅ 验证成功 |
| **B（Service 路径）** | `GTMTLReplayService.update:(GTReplayUpdateLibrary)` | 高 | 接口确认，未执行 |

**路径 A 是推荐路径**：
- 无需构造 GTMTLReplayClient 复杂结构
- 直接在 Controller 路径上操作
- 效果等价

### 2.3 ObjectMap setLibrary:forKey: 签名

```
setLibrary:forKey: — v32@0:8@16Q24
```
- 返回 void，参数：id (MTLLibrary) + uint64_t (key)
- 验证：set 后 get 返回同一指针 ✅

### 2.4 GTMTLReplayService update: 接口

```objc
@interface GTMTLReplayService : NSObject
- (id)update:(GTReplayRequest *)request;  // 返回 GTReplayRequestToken
- (id)initWithContext:(GTMTLReplayClient *)ctx;
// GTMTLReplayClient 结构体包含: apr_pool_t*, GTMTLReplayController*, ...
@end
```

Service 路径需要构造 GTMTLReplayClient（包含 pool + controller + 一系列配置），更适合完整 XPC 场景。

```

结论：AIR 不能直接加载为 MTLLibrary，需先 xcrun metallib 转换
```

### 3.4 函数名不匹配行为

```

[MISMATCH] playAll succeeded (rc=0)
结论：pipeline state 缓存了函数指针，library 替换不影响已链接的 pipeline
      → 需在 replay 开始前（或 rewind 后 populate 前）替换才能生效于新 pipeline 创建
      → 但对 same-name 替换（正常用例），效果完全正确
```

## 4. Xcode UI 能力缺口分析

| 能力 | Xcode GUI | 我们的 API |
|------|-----------|-----------|
| 编辑 shader 源码 | ✅ Edit Source → 自动 recompile | ✅ shaderSource 路径 |
| 用 metallib binary 替换 | ❌ **不支持** | ✅ shaderIR 路径 |
| 用外部编译的 metallib 替换 | ❌ | ✅ `device.newLibraryWithData:` + `setLibrary:forKey:` |
| 对无源码的 shader 做替换 | ❌ | ✅ 只需 metallib binary |
| 从 LLVM IR (.ll) 编译后替换 | ❌ | ✅ `.ll` → `metallib` → 注入 |

**关键价值**：对于只有 metallib/AIR 没有 MSL 源码的 shader（如第三方库、encrypted shader、decompiled IR），
我们的 API 路径可以直接用 metallib binary 替换并验证效果——这是 Xcode UI 完全没有暴露的能力。

## 5. 完整调用流程（推荐路径 A）

```objc
// 1. 准备新 library（从 metallib binary 或从 MSL 编译）
NSData *newMetallib = ...;  // shaderIR: metallib binary
dispatch_data_t dd = dispatch_data_create(newMetallib.bytes, newMetallib.length, NULL, DISPATCH_DATA_DESTRUCTOR_DEFAULT);
id<MTLLibrary> newLib = [device newLibraryWithData:dd error:&err];

// 或从源码编译：
// id<MTLLibrary> newLib = [device newLibraryWithSource:mslSource options:opts error:&err];

// 2. 替换 objectMap 中的 library
SEL setLibSel = NSSelectorFromString(@"setLibrary:forKey:");
((void (*)(id, SEL, id, uint64_t))objc_msgSend)(objectMap, setLibSel, (id)newLib, libraryKey);

// 3. Rewind + Replay
GTMTLReplayController_rewind(controller);
int rc = GTMTLReplayController_playAll(controller);

// 4. 读取结果
NSDictionary *resources = [objectMap resources];
// 对比 texture/buffer 内容变化
```
