# R1.2 技术参考：GTMTLReplay_CLI 签名与 Headless Replay 可行性

**完成时间**：2026-05-20  
**方法**：V1 静态扫描（`dyld_info`、`strings`）+ lldb 离线反汇编  
**结论**：✅ Headless replay 可行 — `GTMTLReplay_CLI` 是独立 C 函数，不依赖 GUI/XPC

---

## 1. 函数签名

```c
int GTMTLReplay_CLI(
    const char *captureArchivePath,          // .gputrace 路径
    GTMTLReplayCLIOptions *options,           // 选项结构体指针
    void (*completionCallback)(NSData *__strong, NSURL *__strong)  // 完成回调
);
```

源文件：`/AppleInternal/.../GPUToolsDevice/GPUTools/GTMTLCapture/replayer/GTMTLReplay_CLI.m`

## 2. GTMTLReplayCLIOptions 结构体（~0xC0 字节）

| 偏移 | 大小 | 名称（推测） | 证据 |
|------|------|-------------|------|
| +0x08 | ptr | device? | 被加载后调用 `defaultCommandQueue` |
| +0x18 | int32 | loopCount | 日志 `"replayCapture, loop count=%d/%d"` |
| +0x25 | uint8 | waitForCompletion | 为 1 时调用 finish → rewind |
| +0x28 | ptr | errorLogPath? | 传给 `stringWithUTF8String:` |
| +0x30 | ptr | saveDestination | 日志 `"options.saveDestination=%s"` |
| +0xa4 | int32 | gpuStateLevel | bit31=禁用，否则 clamp≥2，作为 `@"GPUState"` 值 |
| +0xb8 | uint32 | profilingFlags | 位域 |
| +0xba | uint8 | optimizeRestoresFlags | 低 bits 3-6 控制 `GTMTLReplayController_optimizeRestores` |

### profilingFlags (+0xb8) 位定义

| Bit | 含义 | 证据 |
|-----|------|------|
| bit 6 | ATF_RESULTSDIRECTORY override | `orr w8, w8, #0x40` |
| bit 17 | profileBatchIdFilter | `ubfx w2, w8, #17, #1` |
| bit 21-22 | num_cores 相关 | 在 num_cores≥7 时设置 |

## 3. 执行流程

```
GTMTLReplay_CLI(path, options, callback)
├── apr_pool_create_ex()                       // APR 内存池
├── 创建 parallelQueue + serialQueue
├── if (g_runningInCI) → 日志 "#CI-INFO#..."
├── GTMTLReplayController_makeDataSource(path, pool)
├── mkdir "/tmp/com.apple.gputools.profiling"
├── Metal device 选择（GTMTLSMContext_getDevice / MTLCreateSystemDefaultDevice）
├── GTMTLReplaySupport_init()
├── GTMTLReplayController_makeController()
├── 配置 profiling 字典（profileCounters, MetalPluginName, gpuTarget 等 15+ 键）
├── REPLAY LOOP (loopCount 次):
│   ├── GTMTLReplayController_debugSubCommandStop()
│   ├── if waitForCompletion → finish → rewind
├── GenerateThumbnails
├── if gpuStateLevel ≥ 0 → DerivedCounters 收集
└── completionCallback(data, url)
```

## 6. Headless 最小调用条件

1. `dlopen("GPUToolsReplay.framework")` 成功
2. 合法 `.gputrace` bundle
3. Metal 设备可用（无需 display）
4. 最小 options 结构体（loopCount=1，其余置零）

```c
void* handle = dlopen("GPUToolsReplay.framework/GPUToolsReplay", RTLD_LAZY);
GTMTLReplay_CLI_fn cli = dlsym(handle, "GTMTLReplay_CLI");
char options[0xC0] = {0};
*(int*)(options + 0x18) = 1;  // loopCount = 1
int result = cli("/path/to/capture.gputrace", options, NULL);
```

## 7. XPC 职责分工

| 服务 | 职责 |
|------|------|
| `GPUToolsReplayService.xpc` | Thin stub，仅做进程隔离 |
| `GPUToolsCompatService` | bundle 兼容预处理 |
| `GPUToolsAgentService` | 设备代理 |

**结论**：直接调用 `GTMTLReplay_CLI` 完全绕过 XPC 层，这是 Apple CI 使用的路径。
