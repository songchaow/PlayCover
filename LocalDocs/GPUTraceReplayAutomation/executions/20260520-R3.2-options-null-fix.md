---

## 1. 问题回顾

R3.1 中，真实 .gputrace 样本执行时崩溃：
```
*** +[NSString stringWithUTF8String:]: NULL cString
Call stack: #3 GPUToolsReplay GTMTLReplay_CLI + 3072
```

原因：options 结构体中 +0x28 和/或 +0x30 的 `const char*` 字段为 NULL。

---

## 2. 修复方案

在 `Scripts/replay_probe.m` 中设置以下字段：

| 偏移 | 含义 | 填入值 | 依据 |
|------|------|--------|------|
| +0x28 | errorLogPath (推测) | `"/dev/null"` | R1.2 签名文档标记为 "传给 stringWithUTF8String:" |
| +0x30 | saveDestination | `"/tmp/replay_output"` | R1.2 签名文档确认日志 `"options.saveDestination=%s"` |

代码变更：
```c
const char *errorLogPath = "/dev/null";
*(const char **)(options + 0x28) = errorLogPath;
const char *saveDestination = "/tmp/replay_output";
*(const char **)(options + 0x30) = saveDestination;
```

同时添加 `@try/@catch` 异常捕获，用于后续诊断。
