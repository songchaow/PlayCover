## 集成测试内容

### 测试 1：完整握手流程

```bash
# 1. Initialize
RESPONSE=$(curl -s -D - -X POST http://127.0.0.1:19820/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"integration-test","version":"1.0"}}}')

# 提取 Mcp-Session-Id
SESSION_ID=$(echo "$RESPONSE" | grep -i "Mcp-Session-Id" | cut -d: -f2 | tr -d ' \r')
echo "Session ID: $SESSION_ID"

# 验证响应包含 serverInfo
echo "$RESPONSE" | grep -q "playcover-mcp-gui" && echo "✅ Server info correct" || echo "❌ Server info missing"

# 2. Initialized notification
HTTP_CODE=$(curl -s -o /dev/null -w "%{http_code}" -X POST http://127.0.0.1:19820/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "Mcp-Session-Id: $SESSION_ID" \
  -H "Mcp-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}')
[ "$HTTP_CODE" = "202" ] && echo "✅ Initialized: 202" || echo "❌ Initialized: $HTTP_CODE"

# 3. Tools list
TOOLS=$(curl -s -X POST http://127.0.0.1:19820/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "Mcp-Session-Id: $SESSION_ID" \
  -H "Mcp-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/list"}')
echo "$TOOLS" | grep -q "tools" && echo "✅ Tools list received" || echo "❌ Tools list failed"

# 4. Resources list
RESOURCES=$(curl -s -X POST http://127.0.0.1:19820/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "Mcp-Session-Id: $SESSION_ID" \
  -H "Mcp-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":3,"method":"resources/list"}')
echo "$RESOURCES" | grep -q "resources" && echo "✅ Resources list received" || echo "❌ Resources list failed"

# 5. Ping
PING=$(curl -s -X POST http://127.0.0.1:19820/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "Mcp-Session-Id: $SESSION_ID" \
  -H "Mcp-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":4,"method":"ping"}')
echo "$PING" | grep -q "result" && echo "✅ Ping OK" || echo "❌ Ping failed"

# 6. Delete session
HTTP_CODE=$(curl -s -o /dev/null -w "%{http_code}" -X DELETE http://127.0.0.1:19820/mcp \
  -H "Mcp-Session-Id: $SESSION_ID")
[ "$HTTP_CODE" = "200" ] && echo "✅ Session deleted" || echo "❌ Delete failed: $HTTP_CODE"

# 7. Verify session gone
HTTP_CODE=$(curl -s -o /dev/null -w "%{http_code}" -X POST http://127.0.0.1:19820/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "Mcp-Session-Id: $SESSION_ID" \
  -H "Mcp-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":5,"method":"ping"}')
[ "$HTTP_CODE" = "404" ] && echo "✅ Session expired: 404" || echo "❌ Session still alive: $HTTP_CODE"
```

### 测试 2：安全验证

```bash
# Origin validation
HTTP_CODE=$(curl -s -o /dev/null -w "%{http_code}" -X POST http://127.0.0.1:19820/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "Origin: http://evil.com" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"test","version":"1.0"}}}')
[ "$HTTP_CODE" = "403" ] && echo "✅ Evil origin blocked" || echo "❌ Origin not validated: $HTTP_CODE"

# Missing session ID
HTTP_CODE=$(curl -s -o /dev/null -w "%{http_code}" -X POST http://127.0.0.1:19820/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}')
[ "$HTTP_CODE" = "404" ] && echo "✅ Missing session rejected" || echo "❌ Missing session not rejected: $HTTP_CODE"
```

### Step 2：运行集成测试

实际验证时发现：**不能直接启动 `build/.../PlayCover.app`**。PlayCover 会触发 `AppIntegrity` 检查并弹出“移到应用程序文件夹”提示，因此 GUI 冒烟必须遵循以下流程：

1. 先使用 `BuildScripts/build_and_install.sh`（或等效流程）把 PlayCover 安装到 `/Applications/PlayCover.app`
2. 如需脚本自动拉起 GUI，设置 `PLAYCOVER_APP_PATH=/Applications/PlayCover.app`
3. 不要使用 `open -a PlayCover`，应使用绝对路径 `open /Applications/PlayCover.app`
