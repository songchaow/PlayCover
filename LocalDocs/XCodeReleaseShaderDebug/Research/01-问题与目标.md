# 01 - Xcode Release 包体截帧 Shader 源码不可见问题

## 一、问题描述

在 Xcode 中打开外网包体（Release 构建）的 `.gputrace` 截帧文件时，选中任一 Draw Call 的 Shader，Xcode 弹出：

> **Shader source not found** — No source found
>
> Ensure the Metal Compiler Build Options produces debugging information and includes source code.
>
> If building with the 'metal' command line tool, include the options '-frecord-sources' and '-gline-tables-only'.

提供两个按钮：**OK** 和 **Import Sources**。

## 二、根因

Release 构建的 `.metallib` 不包含调试信息（`-frecord-sources -gline-tables-only`），也没有随附 `.metallibdsym` 符号文件。因此 Xcode 的 Metal Debugger 无法将 GPU 管线状态中的编译后二进制映射回 MSL 源码。

## 三、目标

探索在**不重新编译 app**的前提下，让 Xcode 能显示 shader 的某种可读表示：

| 优先级 | 方案 | 预期效果 |
|---|---|---|
| P0 | 反编译/反汇编 metallib 中的 LLVM IR / GPU ISA | 看到类汇编的可读代码 |
| P1 | 构造伪造的 `.metallibdsym` 注入反汇编结果 | Xcode 原生展示"源码" |
| P2 | 利用 "Import Sources" 按钮手动关联源码 | Xcode 原生展示 |
