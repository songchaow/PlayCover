### metadata 字段映射修复

**问题**：初始实现使用了猜测的 key 名（如 `capturedFramesCount`），实际 plist 使用带前缀的 key。

**实际 key 结构**：
- UUID: `(uuid)` → 特殊 key
- 其余字段带 `DYCaptureSession.` 或 `DYCaptureEngine.` 前缀
- unused 资源计数为 `DYCaptureSession.unused<Type>Count` 系列 key
