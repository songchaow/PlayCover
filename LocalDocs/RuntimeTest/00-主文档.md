# RuntimeTest 问题总览

> 本目录整理 2026-03-30 这轮 PlayCover MCP / GUI / Runtime 实测中遇到的所有问题，便于后续定位、修复与回归。

---

## 一、测试范围

本轮覆盖了以下几类测试：

1. **HTTP MCP 端到端链路**
2. **GUI / MCP 联动的读写测试**
3. **运行时 session 与输入链路测试**
4. **后台 task / SSE 通知测试**
5. **`QQ飞车` 的卸载 / 重装测试**

涉及应用：

- `QQ飞车`（`com.tencent.tmgp.speedmobile`）
- `原神`（`com.miHoYo.Yuanshen`）

测试约束：

- **不允许卸载 `原神`**
- 允许卸载 / 安装 `QQ飞车`

---

## 二、已确认正常的部分

以下链路在本轮测试中表现正常：

1. `Scripts/test_http_mcp.sh` 跑通
2. 附带回归的 GUI build、CLI build、全量测试通过
3. `list_installed_apps`、`get_app_info`、`get_app_settings`、`list_keymaps`、`get_keymap` 可用
4. `update_app_settings`、`create_keymap`、`rename_keymap`、`reset_keymap`、`delete_keymap` 基本可执行
5. `launch_app` 可启动目标 app
6. `uninstall_app` 可卸载 `QQ飞车`

> 注意：上面“可用”不代表没有边缘问题；具体异常见下文问题列表。

## 四、当前环境结论

1. **协议层和基础读写能力大体可用**
2. **运行时 session 链路当前不可用**，导致 tap / swipe / keyboard / overlay 等 GUI 自动化无法继续深入验证
3. **后台 task 实现存在“底层可用、工具层缺口、协议形状不一致”的问题**
4. 给定的 `QQ飞车` IPA **当前无法重新安装成功**，因此测试结束时 `QQ飞车` 未恢复为已安装状态
