# R1.3 技术参考：三层字典结构与 hardwareCountersConfiguration

**完成时间**：2026-05-20  
**方法**：V1 静态扫描（`nm -m`、`strings`、反汇编）  
**结论**：headless replay（GTMTLReplay_CLI）不需要 replayerLaunchDictionary；该字典仅在 XPC/DYGuestAppSession 通路有意义

---

## 1. 三层字典概览

| 层级 | 字典名 | 持有者 | 用途 |
|------|--------|--------|------|
| L1 | `finalLaunchDictionary` | DYGuestAppSession | 底层启动字典（10 键） |
| L2 | `replayerLaunchDictionary` | DYCaptureSession | replayer 专用（7 键，L1 缩减 + bool 开关） |
| L3 | `traceConfigurationDictionary` | DYGuestAppSession | profiling/trace 运行时配置（7 键） |

---

## 2. L1: finalLaunchDictionary（10 键）

`_kDYGuestAppLaunchUUIDKey`, `_kDYGuestAppLaunchArgumentsKey`, `_kDYGuestAppLaunchEnvironmentKey`, `_kDYGuestAppLaunchBundleIdentifierKey`, `_kDYGuestAppLaunchPathKey`, `_kDYGuestAppLaunchCurrentDirectoryKey`, `_kDYGuestAppLaunchTitleKey`, `_kDYGuestAppSimulatorUDIDKey`, `_kDYGuestAppPlatformPrefixKey`, `_kDYGuestAppLaunchDeveloperDirKey`

所有 `_kDY*` 常量从 GPUToolsCore.framework 导入。

---

## 3. L2: replayerLaunchDictionary（7 键）

L1 缩减版 + 三个布尔开关：
- `_kDYGuestAppLaunchReplayer` (bool) — 是否加载 replayer
- `_kDYGuestAppLaunchCapture` (bool) — 是否启用 capture
- `_kDYGuestAppLaunchDiagnostics` (bool) — 是否启用 diagnostics
- `_kDYGuestAppLaunchUUIDKey`, `_kDYGuestAppPlatformPrefixKey`, `_kDYGuestAppLaunchEnvironmentKey`, `_kDYGuestAppLaunchArgumentsKey`

---

## 4. L3: traceConfigurationDictionary（7 键）

| 键常量 | 值类型 | 来源 ivar |
|--------|--------|----------|
| `_kDYTraceModeKey` | uint32 | +0xd8 |
| `_kDYTraceIncludeBacktracesKey` | bool | +0xd4 |
| `_kDYTraceIncludeDriverEventsKey` | bool | +0xd5 |
| `_kDYTraceProfilingSendPeriodKey` | uint64 | `_profilingSendPeriod` |
| `_kDYTraceProfilingFlagsKey` | uint64 | `_profilingFlags` |
| `_kDYTraceHostTypeKey` | uint64 | 固定值 1 |
| `_kDYTraceProfilingHardwareCountersConfigurationKey` | NSDictionary | `_hardwareCountersConfiguration` |

---

## 5. hardwareCountersConfiguration 内部键（候选）

| 键名 | 含义 | 证据强度 |
|------|------|---------|
| `CounterSampleBufferCounterSetName` | counter set 名称 | ⭐⭐⭐ |
| `CounterSampleBufferSampleCount` | 采样数 | ⭐⭐⭐ |
| `profileCounters` | profiling 计数器列表 | ⭐⭐ |

---

## 6. 组装流程

```
DYGuestAppSession
├── _makeLaunchDictionary() → L1
├── _buildReplayerLaunchDictionary*() → L2 → DYCaptureSession._replayerLaunchDictionary
├── _sendTraceConfiguration() → L3 (含 hardwareCountersConfiguration)
└── _sendAllConfigurations() → trace + overrides + additional
```

---

## 7. 环境变量级控制键

| 键名 | 作用 |
|------|------|
| `MTLREPLAYER_ALLOW_PROGRAM_ADDRESS_TABLES` | replayer 地址表 |
| `MTLREPLAYER_OVERRIDE_DEVICE_REGISTRY_ID` | 覆盖目标 GPU |
| `GPUTOOLS_FORCE_ROSETTA` | 强制 Rosetta |
| `GPUTOOLS_XCODE_DEVELOPER_PATH` | 覆盖 Developer 路径 |
| `GPUToolsUseOldTransport` | 旧版 transport |
| `GPUDebuggerDisableResourceCache` | 禁用资源缓存 |

---

## 8. 对 headless replay 的指导意义

- **GTMTLReplay_CLI 路径不需要 L1/L2 字典** — 直接接受 .gputrace 路径 + options 结构体
- **profiling 配置**：CLI 路径下 profilingFlags 直接写入 options 结构体，无需 L3 字典
- **若需 XPC/DY 对象图触发 replay**：需组装 L1+L2+L3 → 复杂度高，推迟到 R3
